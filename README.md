## 🚀 Featured Projects

### 🔍 CrimeNetX

**Crime Scene Reconstruction & Graph Intelligence**

An investigative platform combining crime scene reconstruction, evidence analysis, and AI-powered intelligence.

* Interactive 2D crime scene reconstruction and floorplan visualization.
* Evidence management for weapons, footprints, blood traces, and forced entry.
* Graph-based relationship exploration using Neo4j.
* AI-powered document analysis and retrieval workflows.

**Tech:** Next.js, React Flow, NestJS, PostgreSQL, Prisma, FastAPI, Neo4j

### 🎓 Prashikshan

**Integrated Skill Development & Internship Platform**

An AI-powered platform designed to bridge the gap between students' skills and industry requirements.

* AI-driven skill gap analysis.
* Internship alerts and skilling opportunities.
* Automated internship report generation.
* Role-based dashboards and progressive web app capabilities.

**Tech:** React, Node.js, AI/ML, PostgreSQL, PWA

### 🧠 FocusFlow

**Productivity & Workplace Well-Being Platform**

A productivity platform focused on smarter task management, focus sessions, and workload awareness.

* Smart task management and productivity tracking.
* Focus sessions inspired by the Pomodoro technique.
* AI-assisted workload and burnout indicators.
* Conversational productivity assistance.

**Tech:** MERN Stack, AI Integration

### 🏛️ R-NLAM

**AI-Enabled Land Administration Solution**

A technology-driven project focused on improving land administration workflows through digital tools and structured data management.

* Backend services and database integration.
* Geospatial data infrastructure using PostgreSQL and PostGIS.
* API-driven architecture and modular services.

**Tech:** NestJS, PostgreSQL, PostGIS, Prisma, Python, Docker

### 📊 ALGO_TYPEWRITER

**Sorting Algorithm Visualizer**

An interactive project exploring sorting algorithms and algorithmic problem-solving through visual demonstrations.

**Tech:** JavaScript, HTML, CSS
